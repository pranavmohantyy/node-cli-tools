# node-cli-tools

A collection of useful Node.js CLI utilities. This package includes tools for file operations, HTTP client interactions, and JSON manipulation.

## Installation

You can install this package globally using npm:

```bash
npm install -g node-cli-tools
```

## Usage

After installation, you can access the CLI tools via:

```bash
cli [command]
```

### Available Commands
- `greet`: Prints a greeting message.
- `goodbye`: Prints a farewell message.
- `find [pattern] [dir]`: Finds files matching the pattern in the specified directory.
